# アナウンス音声と連結の改善

アプリの固定台詞2,182件をGemini 3.8 Flash-Lite TTS・Koreで生成し、車内アナウンスをイメージした、落ち着いた明瞭な声へ統一した。音声生成は開発時だけ行い、アプリは同梱MP3を再生する。APIキー・生成原本WAV・有料処理のジョブ記録は公開しない。

## 子供への案内

電車名と最初の文字を順番に再生する。正解後も選んだ文字を発音し、発音が完了するまで次の入力を待つ。最後の車両は最低1.8秒見せ、3つの名前を完成させてからボタンでご褒美電車へ進む。

小さい文字は「ちいさい、ツ」などと案内し、「ー」は「のばす音」と呼ぶ。孤立した「ん」が欠落しやすかった台詞は「ひらがなの、ンです」と文中で明瞭に読む原稿へ変更した。誤読しやすい固有名詞は発音用原稿で補正する。音声ファイルを読み込めない場合の端末読み上げも、同じ発音用原稿を使う。

## 品質検査と再生成

全MP3をデコードして無音・破損を確認し、Gemini 3.8 Flashの音声認識で原稿との一致、読み落とし、余分な語、繰り返しを検査した。認識に疑義がある短い音は第二認識で確認し、サブエージェントが指摘を分類する。確認された不良だけをFlash-Lite TTSで再生成し、圧縮後の実際のMP3を再監査する。

音声認識による照合は、人による聞き取りを完全に代替するものではない。表記差や認識の誤補正を、音声の不良として機械的に扱わない。

最終照合は2,182件すべて回収済み。2,181件は原稿と一致し、残る「おざとろ」の1件も第二の音声認識で正しい発音と確認した。繰り返しの指摘・未検査音声はともに0件。修復後の各音声のハッシュを使って照合している。

再生成方法は[README](../README.md)に記載。全台詞の生成は `scripts/generate-voice-batch.py`、内容検査は `scripts/audit-announcements.py`、対象修復は `scripts/repair-announcements.py`、圧縮・公開用マニフェスト作成は `scripts/publish-announcements.py` が担当する。

## 操作と表示の検証

ユニットテストとブラウザテストで、初回の文字案内、実音声の再生完了、補助ボタンの割り込み防止、最後の連結、3問ご褒美、途中再開、保存不可、タッチ操作、動きを減らす設定を確認した。専用19車種は小画面と大画面で独立レビューし、車体の厚さ・車輪の基準線を揃えた。実装の最終サブエージェントレビューで見つかった代替読み上げの発音問題も修正した。
