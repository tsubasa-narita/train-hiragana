# 書籍候補から追加したごほうび電車10種類

2026年10月4日。既存の26種類と重複しない列車を、出版社の公開目次の134名称から選定。総数36種類。クイズ用とは別の専用イラストを新規生成。

画像生成モード：各列車ごとの新規生成（アニメ・水彩調）。右向き、側面を主体に少し前面が見える角度、窓に小さなクマとウサギ、車体以外は透過。下記の車体形状・塗色をプロンプトに指定。生成後に目視照合し、ひだの帯位置、ライラックの余分な前面窓、銀河の灯具を画像編集モードで修正。背景のぼかしが残った初稿は画像生成ツールで透過し直した。WebP変換ではRGBAのアルファを保持。
