# ことばを よもう

1文字の選択から、短い名前をまとまりとして読む遊びへ進むモード。既存の文字選択・穴埋め・名前連結・なぞり書きは引き続き利用できる。

## 遊びの流れ

1. 2文字・3文字・4文字を明示的に選ぶ。選択は端末に保存し、自動で難しくしない。保護者設定からも変更でき、進行中の旅の長さは固定する。
2. 電車の絵と、同じ文字数の2枚の名前のきっぷを提示。答えの見本や自動の読み上げは出さず、読む時間を確保する。
3. 必要なときだけ「ひともじずつ きく」で名前を開き、各文字を点灯させて音を聞く。開いた各文字も個別に押せる。消音中は「おとを だして きく」から直接利用できる。
4. 正解すると、選んだきっぷ内の文字が順に点灯し、Puckの単文字録音→名前全体の録音へつながる。画像や電車アイコンを新しく挿入せず、答えた場所で完成を示す。
5. 読み終えて約1秒後に次へ。自動送りを止めても進行中の読み上げは最初へ戻さない。手動ではボタンから次へ進む。いずれも画面上部へ移動する。
6. 5問でその回に読んだ5つの名前をきっぷにし、ごほうび電車へ。タップまたはまとめ読みで短く振り返れる。

## 出題

- 2文字6種、3文字30種、4文字29種。小さい文字は入門の範囲外とし、長音と濁音は既存の文字音声で補助する。
- 各長さの中で未記録の電車を優先。同じ旅では5つの異なる電車を選び、各画像の別景色がある場合はランダムに選ぶ。
- 同じ文字数の名前同士を比較し、名前の長さだけを手掛かりに答えられないようにする。
- 候補があれば、先頭が同じ名前を2択にする（こまち／こだま、つばさ／つばめ など）。先頭1文字の照合だけで終わらず、後ろの文字へ目を向ける。ただし同外観の候補は引き続き除外する。
- 同じ外観の車両・塗装を使う列車名同士は2択の対立候補にしない。例：あそ／ゆふ、あずさ／かいじ、ひたち／ときわ、さくら／みずほ、のぞみ／こだま／ひかり、かがやき／たにがわ、わかしお／さざなみ。
- これは名前を読む練習であり、同形式の運行列車を外観だけから厳密に特定させる遊びではない。行の指定は使わない。
- 2文字を増やすため引退列車も採用。あそ・のと・はなは図鑑・紹介音声で過去の列車と分かるようにする。

## 実装と検証

- `src/word-engine.js`：出題、正誤、進行、設定検証。
- `src/word.js` / `word.css`：画面と音声・点灯の進行。再描画・履歴移動で古い音声の完了処理を無効化する。
- `train-word-v1`：長さ、自動送りの設定のみ。図鑑・完走回数は従来と同じ記録へ加算する。
- [2文字の画像生成と実車照合](word-short-trains-sources.md)、[3・4文字の画像生成と実車照合](word-extra-trains-sources.md)。8枚はすべて別々に新規生成。華となすのは公式写真との差異を修正生成した。
- 単体テストは文字数、全体名2択、同外観の候補除外、未記録優先、重複解答防止、設定、音声取消を確認。
- `tests/word-browser.cjs` は320／390／1440pxで、5問完走、初回無音、1音ずつ→名前の順、自動送り切替で読み直さない、設定往復、戻る、画面上端、図鑑、5つの名前のごほうびきっぷを確認。
- 別途320×667pxで消音・3文字・自動送りを確認。Android実機でのタッチ操作は未実施。
- 全62件の単体テスト、静的ビルド、Android相当のブラウザでPWA・戻る・オフライン表示を確認。
- サブエージェントの画面レビューで見つかった自動送り切替時の音声巻き戻り、320pxの折り返し、消音案内を修正し、再レビューで追加指摘なし。
- 追加63録音を音声内容検査。初回5件の名前・濁音の読み違いを修復生成し、再検査で63/63一致、繰り返し0件。文字「づ」の案内は「つに、てんてん」とも説明する。原稿とPuck話者は既存の音声制作手順で管理。
