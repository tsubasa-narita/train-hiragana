# ことばを よもう

1文字の選択から、短い名前の音と文字をまとまりとして結び付けるモード。既存の文字選択・穴埋め・名前連結・なぞり書きは引き続き利用できる。

## 遊びの流れ

1. 2文字・3文字・4文字を明示的に選ぶ。選択は端末に保存し、自動で難しくしない。保護者設定からも変更でき、進行中の旅の長さは固定する。
2. 最初に電車名をPuckの音声で読み上げ、同じ文字数の名前のきっぷを3択・4択で提示する（初期値3択）。読み終えてから回答を受け付ける。問題中は絵を隠し、画像の認識だけで答えられないようにする。「なまえを もういちど きく」で何度でも聞ける。消音中は音声を有効にしてから回答する。
3. 必要なときだけ「ひともじずつ きく」で名前を開き、各文字を点灯させて音を聞く。開いた各文字も個別に押せる。消音中は「おとを だして きく」から直接利用できる。
4. 正解すると電車の絵が現れ、選んだきっぷ内の文字が順に点灯し、Puckの単文字録音→名前全体の録音へつながる。文字は答えたきっぷの中で点灯させる。
5. 読み終えて約1秒後に次へ。自動送りを止めても進行中の読み上げは最初へ戻さない。手動ではボタンから次へ進む。いずれも画面上部へ移動する。
6. 5問で約7秒の3Dごほうび電車へ。ごほうびは独立した映像で、学習した文字との連動はしない。

## 出題

- 2文字6種、3文字30種、4文字29種。小さい文字は入門の範囲外とし、長音と濁音は既存の文字音声で補助する。
- 各長さの中で未記録の電車を優先。同じ旅では5つの異なる電車を選び、各画像の別景色がある場合はランダムに選ぶ。
- 同じ文字数の名前同士を比較し、名前の長さだけを手掛かりに答えられないようにする。
- 候補があれば、先頭が同じ名前を選択肢に優先する（こまち／こだま、つばさ／つばめ など）。先頭1文字の照合だけで終わらず、後ろの文字へ目を向ける。候補が足りない分は同じ文字数の別の名前から補う。
- 音声で列車名を指定するため、同じ形式・塗装のサービスも名前の文字を聞き分けて選べる。
- これは名前を読む練習であり、同形式の運行列車を外観だけから厳密に特定させる遊びではない。行の指定は使わない。
- 2文字を増やすため引退列車も採用。あそ・のと・はなは図鑑・紹介音声で過去の列車と分かるようにする。

## 実装と検証

- `src/word-engine.js`：出題、正誤、進行、設定検証。
- `src/word.js` / `word.css`：画面と音声・点灯の進行。再描画・履歴移動で古い音声の完了処理を無効化する。
- `train-word-v1`：長さ、選択肢数、自動送りの設定。既存設定は3択へ移行し、古い2択の問題履歴も読み上げ付きの3択・4択へ移行する。図鑑・完走回数は従来と同じ記録へ加算する。
- [2文字の画像生成と実車照合](word-short-trains-sources.md)、[3・4文字の画像生成と実車照合](word-extra-trains-sources.md)。8枚はすべて別々に新規生成。華となすのは公式写真との差異を修正生成した。
- 単体テストは文字数、全体名3択・4択、先頭が同じ候補の優先、未記録優先、重複解答防止、設定、音声取消を確認。
- `tests/word-browser.cjs` は320／390／1440pxで、5問完走、全問の初回読み上げ、全体名の再生、正解前の画像非表示、3択・4択と設定の保存、1音ずつ→名前の順、自動送り切替で読み直さない、設定往復、戻る、画面上端、図鑑、5問後のごほうびへの遷移を確認。
- 消音中は回答を止め、「おとを だして きく」から音声を再開できる。Android実機でのタッチ操作は未実施。
- 全64件の単体テスト、静的ビルド、Android相当のブラウザでPWA・戻る・オフライン表示を確認。
- 初回実装時のサブエージェントの画面レビューで見つかった自動送り切替時の音声巻き戻り、320pxの折り返し、消音案内を修正し、再レビューで追加指摘なし。
- 追加63録音を音声内容検査。初回5件の名前・濁音の読み違いを修復生成し、再検査で63/63一致、繰り返し0件。文字「づ」の案内は「つに、てんてん」とも説明する。原稿とPuck話者は既存の音声制作手順で管理。
