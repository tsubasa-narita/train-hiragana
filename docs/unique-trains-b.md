# 専用列車画像レビュー・生成 B

生成日: 2026-09-07

対象は共用画像から専用化する shiosai と muroran。既存アプリの手描きアニメ水彩絵本調、横長構図、少数の動物を保ちつつ、列車形式と主要配色を実車資料に合わせた。画像は image_gen で生成し、生成後のPNGを view_image で目視確認した。WebPはQ88（quality=88）で変換した。

## しおさい

### 公式確認

- [JR東日本 さざなみ・わかしお・しおさい](https://www.jreast.co.jp/multi/traininformation/sazanami_wakashio/)
- [JR東日本公式写真 wakashio_sazanami_img02.jpg](https://www.jreast.co.jp/train/express/img/wakashio_sazanami_img02.jpg)

公式ページと写真で、E257-500系の白い車体、側面の青帯と黄色アクセントを確認した。前面は黄色い外周・屋根上端・下部スカート、白〜灰の中央、黒い窓と左右ライト部分になるよう、親からの照合指摘を受けて前面色を追加修正した。海辺の風景、側面の青白黄、動物は維持した。

### 最終編集プロンプト

既存の横長・手描き水彩絵本調のしおさい画像を編集し、構図、海辺の風景、カモメ、ウサギ、側面の青・白・黄色の車体色を維持する。実車のE257-500に合わせ、前面外周を黄色、屋根上端を黄色、下部スカートと下部前面角を黄色にする。中央前面と中央貫通扉まわりは白〜灰にし、黒は前面窓と左右ライト部分だけにする。前面の大部分を黒にせず、青い前面下部スカートも作らない。前面の左右ライトと中央貫通扉を保ち、側面の青白黄は変更しない。赤・緑の塗装、架空の混成デザイン、文字、ロゴ、透かしは入れない。

### 最終パス

- assets/trains/shiosai-original.png
- assets/trains/shiosai-original.webp

親が専用画像を公式写真と比較して実見し、黄色い前面・スカートを含む前面配色を確認して採用OKとした。

## 室蘭

### 公式確認

- [JR北海道 H100形導入資料](https://www.jrhokkaido.co.jp/press/2018/180215-4.pdf)
- [JR北海道 H100形の公式写真を含む資料](https://www.jrhokkaido.co.jp/corporate/safe/pdf_07/201806.pdf)
- [JR北海道 H100形の運用資料（室蘭線・根室線）](https://www.jrhokkaido.co.jp/CM/Info/press/pdf/20240117_KO_H100.pdf)

公式資料で、室蘭線で使用されるH100形DECMOの銀白色車体、濃い前面窓、緑帯、ディーゼル車の屋根・床下形状を確認した。専用画像は非電化の港湾・海辺の風景にし、H100形の形式が読める前面と銀緑配色を優先した。

### 生成プロンプト

実在するJR北海道H100形DECMOの室蘭本線用車両を、子ども向け日本アニメ水彩絵本調で描く。横長の新規構図。銀白色の一両ディーゼル車、濃いチャコール色の前面窓、緑の側面水平帯と下部アクセント、箱形でコンパクトなH100形の前面、屋根上のディーゼル機器を明瞭にする。室蘭本線らしい静かな湾・港湾工場・低い山の風景、非電化の線路、架線なし。カモメ2羽と遠くの小さなキツネ程度の少数の動物。新幹線形、電車、赤青オレンジの旅客車塗装、架空の混成デザイン、文字、ロゴ、透かしは入れない。

### 最終パス

- assets/trains/muroran-original.png
- assets/trains/muroran-original.webp

親が実画像を確認し、H100形の銀緑配色と形式が読めるため採用OKとした。

コード、src/data.js、src/reward.js、既存の共通画像、gitは変更していない。親側でコードとgitへの統合を行う。
