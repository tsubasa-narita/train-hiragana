# 電車紹介文 A の事実確認記録

確認日：2026年10月21日。対象は `src/data.js` を Node で import して取得した `TRAINS.slice(0, 52)` の52件（`hayabusa` から `chiyoda` まで）。本文は `src/train-facts-a.js` の `TRAIN_FACTS_A`。

各カードに異なる話題を2件、各1文、ひらがな中心で作成した。根拠は運行会社・自治体・教育委員会の一次資料を Web で確認。既存の `docs/prefix-train-sources.md`、`docs/prefix-trains-a.md`〜`prefix-trains-d.md`、図鑑用の調査記録を手掛かりに公式 URL を再確認し、移転先・追加資料を採用した。取得時点の担当52件には `t.sources` がなかったため、各紹介文に直接 URL を付した。`detail` は文章の素材に使用していない。

## 読み方と時制

- 路線・会社名のカードでは路線全体の話題を扱う。名鉄は描かれているミュースカイ、西武線は40000系、室蘭本線はH100形に対応する設備・仕組みを選ぶ。
- 留萌本線は2026年3月31日で最終区間も運行終了済み。沼尻軽便鉄道と昔のロマンスカーも過去の話として記載する。旧型車両の現在運行を示す書き方はしない。
- 以前の仕事（いなほ・踊り子・きぬがわ）と、路線の歴史（平成筑豊・天浜線）は「むかし」で区別する。現行車両そのものが石炭輸送や蒸気運転をしたとはしない。
- 設備は描かれた形式に対応するものを採用。全編成・全席にない設備には「もある」等を使う。しおさいはカードのE257系を対象にし、E259系の設備説明と混ぜない。
- 営業運転をしていない試験車は今回の52件には含まれない。将来の新車・変更計画、最高速度、時刻、料金は紹介文に採用しない。運行区間は通常のサービスの説明であり、毎便が全区間を走るとの意味ではない。
- 画像を見れば分かる色・形・車両番号・窓・動物・車体サイズの説明は含めない。「まどがわ」は車内コンセントの設置対象となる座席を示す語で、窓の外観説明ではない。
