# Mendel：関東の地域鉄道5件

確認日：2026-11-10。`src/new15-mendel.js` に車両と紹介文を登録。各画像は `assets/trains/n15-mendel-<車名>.png` と同名の `.webp`。PNGは内蔵 image_gen の生成結果、WebPは変換結果。

既存の `src/data.js` およびインポート先を照合し、流鉄・小湊・銚子・鹿島臨海など既収録路線を除外。以下5路線は互いに別路線で、常総線と真岡線は下館駅で接続する。人気の定量比較は未実施。

共通の生成指示：子供向け水彩アニメ風、横長、斜め前から車両を大きく描き、沿線風景と小動物を少し、文字・ロゴなし。背景と動物は創作。以下に個別の指示と照合結果を記載する。各1回生成し、目立つ違いのある4件は再生成した。上毛線と湊線は追加の照合後にさらに再生成した。

## 常総線 キハ5000形
[公式車両写真と説明](https://www.kantetsu.co.jp/train/traincar)／[路線図](https://www.kantetsu.co.jp/train/routemap/)。白い単行気動車、中央貫通扉、青・赤の帯、田園と兎を指示。複数案から配色が近い絵を選んだ。青帯は実車より太く、窓・灯火や台車は概略。

## 竜ヶ崎線 キハ2000形
[公式車両写真と説明](https://www.kantetsu.co.jp/train/traincar)／[路線図](https://www.kantetsu.co.jp/train/routemap/)。白い単行気動車、中央貫通扉、青と赤の帯、茨城の町とリスを指示。白地・赤い細帯・青い下帯・中央扉は共通。帯の太さ、側窓・灯火・機器配置は実車と異なる。

## 真岡線 モオカ14形
[公式実車写真と形式説明](https://www.moka-railway.co.jp/19139/)／[路線図](https://www.moka-railway.co.jp/route-map/)。緑の濃淡の市松模様、赤い下部、中央貫通扉、単行気動車、田園と兎を指示。初回は市松模様が欠けたため再生成。再生成後は市松と赤い裾を確認できるが、模様は実車より大きく、灯火・窓・扉は概略。

## 上毛線 800形（811編成）
[公式車両写真](https://jomorailway.com/train_guide.html)／[実車の側面写真](https://dencs.net/reiwa/img/070131_1.jpg)／[路線案内](https://jomorailway.com/line.html)。追加再生成の指示：銀色2両、前面のみパステルブルー、大きな黒い前面窓と縦仕切り、中央貫通扉なし、側面に細い緑と赤の2本帯、青帯を側面に延ばさない、パンタグラフ、鳥。実写と比較し、青い前面と側面の緑・赤帯の分離、前面窓の縦仕切り、2両とパンタグラフを確認。絵では前面の青い部分が写真より大きく、前面下部・灯火や側窓、台車の配置は概略。

## 湊線 キハ11形
[公式車両情報](https://www.hitachinaka-rail.co.jp/train/)／[駅一覧](https://www.hitachinaka-rail.co.jp/timetable/)／[キハ11-5の実車写真](https://railf.jp/news/2016/01/02/193000.html)。追加再生成の指示：白い単行気動車、オレンジ帯1本で緑帯なし、前面の大きな黒い窓枠と白い中央貫通扉、海沿い、兎。実写と比較し、白地にオレンジ帯1本、黒い前面窓枠と中央扉を確認。絵では橙帯が貫通扉までつながり、窓や灯火・台車の配置や細部も写真と異なる。鉄道会社の公式車両ページは取得がタイムアウトし、公式写真との直接照合は未完了。

路線の fact は沿線や路線全体を示し、当該形式が毎日全区間を運行することを保証しない。実車の塗装・運用は変わりうる。
