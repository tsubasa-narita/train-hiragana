# 流用していたクイズ画像の再制作

対象は、クイズ・図鑑で使用中だった旧アプリ由来の28枚。640×640、1024×1024、1254×1254の正方形、1024×687の旧はやぶさ、2172×724の湘南新宿ラインを、新しい1536×1024（3:2）の風景付きイラストへ差し替える。

単純な拡大・引き伸ばし・切り抜きではなく、組み込みImageGenで1枚ずつ新しく生成。車種を確認できる形と塗装を優先し、水彩アニメ絵本風、側面の窓に小さな動物を少し描く。ごほうび用の横向き透過画像は別の用途のため、この差し替えの対象に含めない。

個別の記録に実車確認の出典、採用した形式、最終プロンプトと確認結果を記載する。

親エージェントが公式写真を直接参照した最終修正：[スペーシアX](legacy-image-renewal-spacia-x.md)、[副都心線10000系](legacy-image-renewal-fukutoshin.md)。旧ロマンスカーとサンライズの修正はCの記録に含めた。

## アプリへの反映

PNG原本と配信用WebPは`assets/trains/renewed-*`に保存。対応表は`src/quiz-images.js`に集約する。電車データと別画像のカードは読み込み時に新しいファイル名へ変換する。クイズ・図鑑・なぞり・穴埋め・連結の表示時にも旧ファイル名を解決し、更新前のブラウザ履歴に保存された途中状態から復帰しても新しい絵を使う。

電車ID、文字の対応、学習記録は維持する。旧ファイルは比較・以前のクライアントの参照用として保持する。サービスワーカーをv20へ更新し、既存のAndroidアプリにも新しいコードを配信する。
