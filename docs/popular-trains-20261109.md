# 追加した観光列車（2026年11月）

既存の図鑑に独立した車両として収録されていなかった列車を選び、車体の色や形、運行地域は各鉄道会社の資料で確認した。クイズの絵は子ども向けに動物や景色を加えたイラストであり、実車の写真ではない。

選定の参考として、[旅色の読者アンケート](https://tabiiro.jp/higaeri/article/zenkoku-densha/)では青の交響曲が紹介されている。[日本旅行の鉄道ファンによるおすすめ](https://www.nta.co.jp/media/tripa/articles/3HzQu)にはA列車で行こう、ふたつ星4047、指宿のたまて箱が含まれる。各調査は対象者が限られ、全国の子どもの人気順位を示すものではない。その他は、地域や色、形の多様さも考慮して選んだ。
