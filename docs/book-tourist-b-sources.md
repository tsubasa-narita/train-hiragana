# 観光列車ブック B：出典と画像制作メモ

## 既存データとの重複確認

指定された18名称を `src/data.js` と `src/train-expansion.js` の既存列車データに照合した。既存項目に同一車両を特定できるものはなく、重複登録として除外する項目は0件。一般的な阪急車両画像は「水都」と同一車両ではないため代用しない。

## 生成画像の共通指示

各車両の公式資料で確認した前面形状・車体色・帯・編成長を固有に反映する。横長1536×1024の絵本向け水彩・アニメ調。列車を画面の約65–75%に大きく配置し、全体の形と前面を見せる。車窓または開放デッキには小さなくまとウサギの乗客を描く。明るい沿線風景、文字・数字・ロゴ・透かしなし。各車両ごとに新しい独立画像を生成する。データの `name` は既存・報酬データの長音表記に合わせ、指定された車両名では「ー」を使う。
