# もじをのせよう：1文字の穴埋め

2026-10-11。既存「なまえをつなごう」を残し、長い名前も1回答で完成する新モードを追加。

## Astraとの設計検討

先頭から数文字を順番に答える方式、1文字穴埋め、見本との照合、1択の操作練習、文字のまとまりを選ぶ方式、音だけの穴埋めを比較。Astra（gpt-6-astra）の助言を受け、見本付き2択の1文字穴埋めを既定にした。既存の全字連結とは別の状態管理にし、名前の長さで操作回数が増えない。

- 名前の穴は毎回1か所。先頭以外も対象。同じ電車の前回の穴位置を保存し、候補が複数あれば別位置を選ぶ。
- まず好きな電車を選べる。おまかせも可能。1回5問、選択した行・文字の難易度は旅の間固定。行選択は穴にする文字へ適用する。このモードの穴は五十音順ではなくランダム。
- 名前全体は折り返し、操作場所には穴と前後1文字を大きく表示。文字数で操作部分が縮小しない。
- 最初は清音。濁音・半濁音・小さい文字・長音は完成済みで残し、保護者設定で穴の対象にもできる。濁点等を独立した回答に分けない。
- 見本付き2択、正解のみの1択、見本なし音声2択を保護者が選べる。成功回数による自動難易度上昇はしない。
- 間違いは減点・ブザーなし。正しい文字を案内し、同じ問題を1択にして補助する。「おてつだい」でも利用できる。
- 5問完成で既存のごほうび電車。完成音声と最低1秒の演出を待ち、その後約1秒で次へ。自動進行をその場で停止、または保護者設定で手動にできる。以前の自動遷移の希望を維持しつつ、Astraの「完成を眺める時間を残す」助言を取り入れた。

## 音声と画像

出題は既存の `questionText`（電車名→対象文字→同じ文字を探す案内）。正解は対象文字→その電車名を含むほめ言葉→効果音。誤答では押した誤字を読まず、正解文字とヒントを案内する。

全録音を既存のGeminiアナウンス音声から再利用。新規生成は不要。電車画像と19車種の透明車両素材も再利用し、完成時に短い3両の連結を表示。背景付き電車の写真全体を走行素材として移動させない。

音声中の入力は重複を避ける。「すぐあそぶ」で出題音声を中断でき、消音も常に使える。音声2択でも、消音・再生失敗時は見本を出す。録音が停止したままの場合も12秒で待機を解除する。

## 状態と検証

問題ごとに履歴を積まない。Androidの戻る相当のブラウザ戻る、設定からの復帰、再読み込みでは、同じ穴・選択肢・完成数を保持。古い音声・タイマーは画面を変更しない。完走IDを保存して同じ旅の完走回数の二重加算を防ぐ。保存失敗でもそのまま遊べる。

Astraの実装レビューで、音ON時の確認音声による割り込みと、履歴移動開始からpopstateまでの旧コールバックを修正。

自動テスト：全電車の1回答完成、各行への限定、文字種の設定、穴位置の変化、誤答支援、連打、保存データ、既存録音の網羅、音声取消と履歴移動。ブラウザでは375×812で湘南新宿ライン、設定からの復帰、誤答→1択、消音、5問完成、ごほうびを戻る操作で閉じる流れを確認。実機Androidの手元確認は未実施。
