# 「もじをみつけよう」の選択肢・電車紹介・Puck音声

2026-10-26更新。

## 選択肢

「おうちのかたへ」で、見本の有無とは別に2択・3択を保存する。初回は見本あり2択。旧設定からの移行では見本あり2択／音声3択を保ち、明示的に選んだ数は見本の設定を変えても維持する。設定からブラウザの戻る操作で同じ問題へ戻った際も反映する。

## 紹介の内容と出典

全213車種にそれぞれ2文、合計426文を用意。共通の文をまとめると422種類。すべての紹介に、走る地域・路線・発着地のいずれかを含める。色・形・窓・車体番号など、画像で分かる外観の説明は使わない。運行範囲や経由地を、運行会社・公的機関等の資料で確認した。

データは `src/train-facts-a.js`〜`src/train-facts-d.js`。全紹介に根拠URLの`source`を付け、確認内容・適用する車種・時制は次の記録にまとめた。

- [車種1〜52の根拠](train-facts-a-sources.md)
- [車種53〜104の根拠](train-facts-b-sources.md)
- [車種105〜156の根拠](train-facts-c-sources.md)
- [車種157〜205の根拠](train-facts-d-sources.md)
- [首都圏の追加8車種の根拠](capital-train-additions-20261026.md)

追加8車種のデータは `src/capital-trains.js`。全紹介に地名・路線名の `places` を付け、各語が読み上げ本文にも含まれることを検証する。

昔の列車・廃線は過去形、E10等の開発中の車両は設計・試験として紹介。特定形式の設備を別形式へ当てはめない。各列車・全座席への一律適用を避ける。時刻や最高速度は採用しない。場面問題「でんしゃをみる」も、画像の京急に対応する紹介を使う。

## 切り替えと保存

正解時に紹介を1件選び、電車IDごとに最後の紹介番号を`recentFacts`へ保存する。前回と同じ紹介は候補から外し、再起動しても続きから切り替える。画面の再描画や音のON/OFF、設定・履歴からの復帰は、保存した同じ紹介を使い、画面と音声を一致させる。旧来の外観説明へはフォールバックしない。ヒント音声は「ひらがなの○」と対象を明示し、短い音が別の単語に言い換わらないようにする。

紹介の読み上げが終わるまで次へ進まず、正解の表示は最低1秒維持する。消音でも同じ紹介文を表示。「いま すすむ」は音声とタイマーを止める。ホームや設定へ移動しても旧画面のタイマーは動かない。

## 声と制作

全2693台詞を、試聴用と同じ `gemini-3.8-flash-tts`・`Puck`、`cheerful, friendly, encouraging, clear and slightly unhurried` で録音。紹介だけでなく問題、文字、各モード、ほめ言葉、ごほうびの声を統一する。一文字には、同じPuckで日本語の音を1回だけ明確に発音し、笑い声や英語の相づちにしない専用の指定を加える。

`scripts/puck-profile.json`で設定を固定。`node scripts/voice-manifest.mjs`の後、`python scripts/puck-narration.py submit` / `collect` / `publish`を順に実行する。プロファイルの異なる録音を再利用せず、公開用MP3は新しい`assets/voice/puck/`へ保存。サービスワーカーも世代を更新し、古いKoreのキャッシュと混ぜない。

原本と有料ジョブの記録は`.tools/`で保持する。一時的なファイルロックは保存済み結果から回復し、生成を重複送信しない。プロセス間の排他でsubmit/collect/publishを同時実行できないようにした。APIキー・原本WAVは公開しない。通常のプレイ中に生成APIは呼ばない。

## 検証
