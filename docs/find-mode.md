# 「もじをみつけよう」の選択肢と電車紹介

2026-10-21。

「おうちのかたへ」で見本の有無と別に2択・3択を保存する。初回は見本あり2択。以前の設定からの移行時は見本あり2択／音声3択を保ち、明示的に選んだ数は見本の設定を変えても維持する。設定からブラウザの戻る操作で問題へ戻った際も反映する。ほかの遊び方の選択肢には影響しない。

正解後は汎用の「できたね！」を、出題画像の電車に対応した短い紹介へ変更。画面にも同じ文を表示する。203種類の紹介文で全205車種・別景色・「を」の場面問題をカバーする。場面問題の「でんしゃをみる」は電車名として扱わず、画像に対応する京急の説明を使う。

紹介は読み終わるまで自動遷移を待ち、最低1秒の正解表示は維持する。消音でも紹介文を表示。「いま すすむ」は音声とタイマーを止めて次へ進む。設定やホームへの移動も音声を止め、正解画面に戻った場合は紹介から再開する。紹介中に音をONにした場合も、紹介を読み終わってから進む。

## 紹介文の根拠

`src/train-facts.js`で電車IDと紹介文を対応づける。基本は図鑑の既存`detail`を再利用し、車両の見た目・役割・沿線の短い説明にする。過去の車両・鉄道の「むかし」の説明は維持し、現役とは断定しない。既存の調査出典は各車両の`sources`と、本フォルダの`book-*-sources.md`、`prefix-train-sources.md`、`design-review*.md`等に記録されている。

今回追加した文は2026-10-21に次の運行会社資料で確認した。最高速度やダイヤのような変わりやすい情報は新規文に使用しない。

- はやぶさ：緑の車体と長い先頭部。[JR東日本 E5系](https://www.jreast.co.jp/train/shinkan/e5.html)
- 山手線：東京の環状運転。[JR東日本 山手線環状運転100周年](https://www.jreast.co.jp/press/2025/tokyo/20250916_to02.pdf)
- 御堂筋線：大阪を走る地下鉄。[Osaka Metro 路線情報](https://subway.osakametro.co.jp/station_guide/index.php)
- ラピート：大阪なんばと関西空港を結ぶ特急。[南海電鉄 ラピート](https://www.nankai.co.jp/traffic/express/rapit.html)

## 音声

既存のGemini Flash-Lite TTS・Kore・車内アナウンス風の設定で紹介文を録音。生成は`node scripts/voice-manifest.mjs`、`python scripts/generate-announcements.py --facts`、`python scripts/publish-announcements.py`。APIキーは端末内のみで扱い、静的サイトへ含めない。

同期生成の日次上限に達したため、残り104件は既存の一括生成手順で同一モデル・声・スタイルを使用して生成した。新規203件、約5.9MBのMP3を追加し、既存分を含む全2385録音をデコードして無音・破損を検査。代表16件を音声の書き起こしと照合し、すべて一致した。
