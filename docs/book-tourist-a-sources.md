# Tourist train book entries: research and artwork

This file records the exact-name comparison, model/livery research, illustration cues, and source URLs for `BOOK_TOURIST_A_TRAINS` in `src/book-tourist-a.js`.

All 18 requested names were checked against the current `TRAINS` data. None is already represented by an exact train-specific entry, so all 18 receive their own quiz illustration. The generic `heisei-chikuho` entry does not represent the dedicated ことこと列車. These are full-scene quiz illustrations; the separate transparent reward art being made by the parent task is not reused here.

## Shared illustration brief

Each new image is a distinct 1536×1024 landscape watercolor/anime picture-book scene. The documented train fills roughly 65–75% of the composition; a small bear and rabbit ride in passenger windows; the route scenery supports the train's region. The prompts specify the real body type, cab/nose, consist and principal livery cues, and prohibit invented text/logos. Final assets are converted from the generated raster to RGB WebP at quality 86 without resizing.

## Scope notes

- No assigned entry was skipped or mapped to an existing generic train; all 18 are represented by distinct files and unique IDs prefixed `book-`.
- こたつ列車 is explicitly labeled as a Sanriku 36-Z representative because the name refers to a train service concept rather than one universally fixed vehicle.
- Generic open-deck or locomotive-only categories outside the assigned list are not added here.
- The five reward illustrations commissioned separately by the parent task are separate transparent assets and are not substitutes for these quiz scenes.
