# 3つのごほうび映画

承認された完成イメージ A・B・C を、実際にカメラと電車が動く約10秒のWebGL映像として実装。静止画のスライドではなく、Three.jsの車体・車輪・線路・風景を描画する。

| 舞台 | 見せ場 |
| --- | --- |
| ひみつの車庫 | ライト点灯、シャッター開放、金色の光の中で加速して出庫 |
| 夜景 | 足回りのアップから追走、濡れた高架と街の明かり、別編成とのすれ違い |
| 天空の橋 | トンネルから曲線橋へ、雲海と海、虹を見せる空撮への引き |

各舞台に横須賀線・湘南新宿ライン・埼京線・東横線・山手線・こまち・はやぶさの7編成を組み合わせ、計21通り。端末に残るシャッフル袋から未再生の組み合わせを選び、一巡してから補充する。可能なら舞台と電車を両方変更する。最後の組み合わせでは全種類を消化することを優先する。1回の完走につき自動再生は1回。再生後は「でんしゃ ずかん」「おしまい」の2択。ブラウザの戻る／進むで視聴済みの演出へ戻っても自動再生を繰り返さない。図鑑は表示中の主役車両へ開く。

カーブ区間は各車両を同じ半径600mの線路に配置してから編成を移動する。毎フレームの大量のインスタンス行列更新を避け、車輪は車両ローカル軸で回す。低速端末は解像度と影を抑え、時間は変更しない。動きを減らす設定ではカメラの移動を抑える。バックグラウンドでは停止し、復帰時に残りを再開。終了時は全シーンのGPU・音声リソースを解放する。

採用した生成コンセプト・プロンプトは `design/reward-concepts/2026-11-12/`。ブラウザで動作する実装はスマートフォンの描画負荷に合わせた表現であり、生成画像と同じレンダリング品質を保証するものではない。天空の橋の地形は架空。

## 10秒の演出構成

全21通りで同じ時計を共有する。0〜1.1秒はライト点灯と期待感、1.1〜3.2秒は低い視点からの発車、3.2〜7.8秒は舞台固有の見せ場、7.8〜10秒は先頭車を大きく見せる締め。列車は1.1秒から加速し、4.6秒で巡航速度に達する。カメラが切り替わっても位置・速度は連続する。

天空の橋では列車がトンネル内から現れ、霧が両脇へ流れ、虹が景色の中に広がる。車庫はシャッターが開いてから日なたへ出庫し、夜景は5.3秒付近のすれ違いと終盤の2輪の花火を見せる。主役の塗装・形状は維持し、景色を架空の祝祭的な舞台として扱う。

浮遊する光の粒と、線形HDRへの小さなハイライトのにじみ・色調整を追加。端末で映像をリアルタイム描画し、低速時は解像度と影を調整する。動きを減らす設定ではカメラを広い安定した構図に固定し、花火を省略する。

音は車名の既存Puck録音に、静かな期待音・加速する合成モーター・走行音・終盤の短いファンファーレを重ねる。実車の録音ではない。5.3秒のすれ違い、8.2秒からの音楽も映像と同じ時計で鳴る。消音やバックグラウンドからの復帰では経過位置から再開し、最初から鳴らし直さない。

再生中は見出しを小さくして映像を拡大し、「おしまい」は常に押せる。再生は自動で1回、終了後の選択肢は「でんしゃ ずかん」「おしまい」の2つ。10秒への延長でこの操作や履歴の仕様は変えない。
