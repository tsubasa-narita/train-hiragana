# 10ののごほうびコース

承認された完成イメージ A・B・C を、実際にカメラと電車が動く約10秒のWebGL映像として実装。静止画のスライドではなく、Three.jsの車体・車輪・線路・風景を描画する。

| 舞台 | 見せ場 |
| --- | --- |
| ひみつの車庫 | ライト点灯、シャッター開放、金色の光の中で加速して出庫 |
| 夜景 | 足回りのアップから追走、濡れた高架と街の明かり、別編成とのすれ違い |
| 天空の橋 | トンネルから曲線橋へ、雲海と海、虹を見せる空撮への引き |
| 桜の渓谷 | 花びらが舞う渓谷と赤い鉄橋。カメラを引いて川と車両を見渡す |
| 雪山 | 青い夕暮れと雪が積もった針葉樹、窓に灯りがともる集落 |
| 海底トンネル | ガラスのトンネルの中から外へ引き、魚の群れと頭上を横切るマンタを映す |
| 鉄道模型 | 赤い操作ダイヤルが回って発車。真上から家、道路、小さな自動車を見渡し、先頭車の低い視点へ戻る |
| おもちゃ部屋 | 信号が変わると青いレールの4両編成が発車。積み木とぬいぐるみの横を抜け、赤い橋を渡る |
| おもちゃ遊園地 | 青いレールから赤い橋へ進むと、ゴンドラを下げた観覧車が回る |
| おもちゃ宇宙 | 紫のレールとクレーターのある月面。わきをロケットが発射する |

各コースと12車種を組み合わせて計120通り。端末に保存した未再生の組み合わせから選び、一巡してから補充する。可能なら舞台と電車を両方変更する。更新時は視聴途中の一巡分に追加コースの組み合わせを加える。1回の完走につき自動再生は1回。再生後は「でんしゃ ずかん」「おしまい」の2択。ブラウザの戻る／進むで視聴済みの演出へ戻っても自動再生を繰り返さない。図鑑は表示中の主役車両へ開く。

カーブ区間は各車両を同じ半径600mの線路に配置してから編成を移動する。毎フレームの大量のインスタンス行列更新を避け、車輪は車両ローカル軸で回す。スマートフォンでは画素数と影の更新頻度を抑える。実測の描画間隔が長いときは解像度と仕上げ処理を段階的に下げ、10秒の再生時間を保つ。動きを減らす設定ではカメラの移動を抑える。バックグラウンドでは停止し、復帰時に残りを再開。終了時は全シーンのGPU・音声リソースを解放する。

採用した生成コンセプト・プロンプトは `design/reward-concepts/2026-11-12/`。ブラウザで動作する実装はスマートフォンの描画負荷に合わせた表現であり、生成画像と同じレンダリング品質を保証するものではない。天空の橋の地形は架空。

## 10秒の演出構成

全120通りで同じ時計を共有する。0〜1.1秒は発車前、1.1〜3.2秒は発車、3.2〜7.8秒は舞台固有の見せ場、7.8〜10秒は先頭車を大きく映す。列車は1.1秒から加速し、4.6秒で巡航速度に達する。カメラが切り替わっても位置・速度は連続する。

おもちゃ部屋では既存の車種を4両に組み替え、樹脂成形品のような光沢で描く。成形された青いレールの継ぎ目、橋脚のブロック、信号、風車、ぬいぐるみを立体化し、発車音と信号の変化を合わせる。

海底トンネルと鉄道模型は架空の舞台。海底はガラスと水面の反射、泳ぐ生き物、水中風の合成音を同じ時計で進める。鉄道模型では木の台と定規を入れて縮尺を見せ、発車に合わせて信号と操作ダイヤルを動かす。

天空の橋では列車がトンネル内から現れ、霧が両脇へ流れ、虹が景色の中に広がる。車庫はシャッターが開いてから日なたへ出庫し、夜景は5.3秒付近のすれ違いと終盤の2輪の花火を見せる。主役の塗装・形状は維持し、景色を架空の祝祭的な舞台として扱う。

夜のすれ違いは線路を見下ろす構図で両編成を見せる。終盤は先頭車の斜め前へ回り込み、縦画面でも運転席とライトを大きく映す。夜空には金色と車両色の花火が順に開き、火の粉が尾を引いて落ちる。端末で映像をリアルタイム描画し、低速時は解像度と影を調整する。動きを減らす設定ではカメラを広い安定した構図に固定し、花火を省略する。

音は車名の既存Puck録音に、静かな期待音・加速する合成モーター・走行音・終盤の短いファンファーレを重ねる。実車の録音ではない。5.3秒のすれ違い、8.2秒からの音楽も映像と同じ時計で鳴る。消音やバックグラウンドからの復帰では経過位置から再開し、最初から鳴らし直さない。

再生中は見出しを小さくして映像を拡大し、「おしまい」は常に押せる。再生は自動で1回、終了後の選択肢は「でんしゃ ずかん」「おしまい」の2つ。10秒への延長でこの操作や履歴の仕様は変えない。
