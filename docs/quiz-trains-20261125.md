# クイズに追加した電車10種類

各車両の公式写真で先頭部・帯・窓・灯具を確認した。掲載画像は ImageGen で描き起こし、`assets/trains/quiz-*.webp` に 1200 × 800 の WebP で収録した。車内の小さな動物や風景はイラストとして描き加えた。

## 生成指示

横3:2の幼児向けクイズ画像。車両写真を車体形状と塗装の資料にし、アプリの「かがやき」の水彩アニメ風イラストを画材と雰囲気の資料にする。電車は1編成だけを大きめの斜め前から描く。スマホで切り抜かれても先頭と車体の一部が読める構図。客室窓に小さなウサギ・クマ・キツネなどを1〜2匹。文字の重ね書きや透かしは入れず、次の実車の特徴と沿線を描く。
