# なぞって はしろう

ホームの3つ目のモード。清音46文字・104画に対応。
ホームで選択した行を引き継ぎ、モード内でも行・文字を選べます。
次の文字は五十音順。「つぎの もじへ」で画面の先頭へ戻り、電車名と文字を読み上げます。
5文字完成すると約1秒後に完走画面と既存のごほうび電車を表示します。
途中の文字は絵を眺めてから自分のペースで進みます。やり直しでは同じ問題を二重に数えません。
絵はクイズと同じ候補から選び、実在する名前の先頭を優先します。
「を」「ん」のみ例外。同じ文字を次回選ぶと、前回完成した絵を避けます。

## 操作と判定

- 金色の線が今の画、薄い線が残りの画、緑の線がなぞった部分。
- 番号の電車から始め、現在の画を終えて指を離すと次の画へ。
- 電車は曲線の接線に向きを合わせ、指の進み方に合わせて動きます。
- 109×109の字形座標で判定し、画面サイズによらず同じ許容幅を使用。
- 開始位置は電車から10単位以内、線から10単位までのずれを許容。
  以前の開始8単位・線7単位より広くし、小さな指のはみ出しを受け止めます。
- 最後まで順に進んだ場合は、残り4単位以内（短い画では全長の15%以内）で、
  指が終点から10単位以内なら完成にします。終点ぴったりで止める必要はありません。
- SVGを約0.6単位ごとに標本化。入力の移動も最大1.5単位ずつ補間し、
  現在位置から先の4単位だけを探索。交差点や輪の近道を防ぎます。
- 線から外れると電車はその場で待機。離した指を電車に戻せば続けられます。
- Pointer Eventsとpointer captureを使用。副の指を無視し、キャンセルにも対応。
  ブラウザ標準のスクロールは筆記面だけで止めます。
- お手本は今の画だけを低速で走ります。お手本の再生は完成判定に加えません。
  reduced-motionでは動かさず矢印を案内します。
- 完成時は絵・チャイム・既存の録音済みのほめ言葉を表示し、図鑑に記録します。
- 履歴に現在の文字・絵・画・筆記位置を保存。設定から戻る・再読み込みでも復元。
  画面移動時はイベント、描画アニメーション、ポインター捕捉を解除します。

## 字形とライセンス

手書き用の「き」4画、「さ」3画など、KanjiVGの筆画をそのまま採用しています。
出典・固定リビジョン・CC BY-SA 3.0の表示は
[vendor/kanjivg/NOTICE.md](../vendor/kanjivg/NOTICE.md) とモード内にあります。
`node scripts/derive-kana.mjs` で同梱SVGからデータを再作成できます。
外部通信も字形フォントのインストールも不要です。

## 検証

- `npm test`：46文字の原典一致、画像候補、方向・近道・中断・復元の判定。
- `node tests/trace-browser.cjs`：Edge/ChromiumのPixel 7相当環境で、46文字104画すべてを
  CDPタッチ入力で完走。書き順違い・逆向き・お手本・途中再開・設定から戻る・再読み込み・
  オフライン・動きを減らす設定・320px幅も検証。
- `node tests/trace-input-browser.cjs`：複数の指、マウス、はみ出し、移動中のお手本中断、保存不可を検証。
- 既存のクイズ、行選択、Android/PWAの回帰テストも実行。

Android実機上での確認ではなく、ブラウザのモバイル・タッチエミュレーションでの確認です。
画像・音声のオフライン利用は取得済みのファイルに限ります。

追加回帰テスト：`node tests/trace-journey-browser.cjs`（スクロール、録音案内、5文字ごほうび、履歴、再開）。
