# Legacy train illustration renewal (C)

This batch replaces the seven square, framed legacy illustrations with full-bleed 1536 × 1024 landscape assets. Each PNG is the generated image output (the Sunrise PNG is the corrected edit output); its WebP companion was encoded from that PNG at quality 88, method 6. No legacy source image was stretched or cropped.

All base illustrations use the watercolor-anime picture-book treatment of `assets/trains/hitachi.webp` as a style reference. The composition is a three-quarter front view with several cars, one train, gentle landscape, and small animal passengers only in side passenger windows where appropriate. The Momotaro freight image has no animals because the freight cars have no passenger windows. Prompts below are the actual generation prompts; the Sunrise section also records the localized corrective edit.
