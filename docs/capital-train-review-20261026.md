# 首都圏追加車両画像レビュー（2026-10-26）

8枚すべてを `view_image` で確認し、各社・交通局の公式車両写真と照合した。判定対象は前面形状と実車の大きな配色差。動物の位置や小さな部品の省略、絵柄による細部の簡略化は判定から除いた。

## 確認上の留意点

- 京王1000系は編成ごとに帯色が異なる。今回の青系の帯色だけを理由に不一致とはしない。
- 相模線E131系500番台は、公式写真と前面の主要形状・青い模様を照合した。絵の細部や動物の配置は実車との差として数えていない。
- TX-3000系は公式写真より前面の傾斜が強めに描かれているものの、色分けと大枠の前面構成は一致するため、明白な形式違いには分類しない。
