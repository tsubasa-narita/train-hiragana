# ごほうびの鉄道3Dシネマ

2026-11-11。学習した文字を表示する従来のごほうびを、独立した約7秒の鉄道映像へ置き換えた。

## 表示と操作

- 横須賀線E235系1000番台11両、湘南新宿ラインE233系3000番台10両、埼京線E233系7000番台10両、東横線5050系8両。
- 実寸に近い車体、開口部のある窓と扉、室内、2階建てグリーン車、床下機器、台車、回る車輪、パンタグラフを実際の3D形状で描く。[実車の一次資料・造形仕様](reward3d-vehicles.md)。
- 読み込み後に自動発車。先頭車の低い視点から追走し、最後は編成と高架線を見渡す。川、街並み、空と雲、架線、枕木とレールも立体またはシェーダーで描く。実在の特定地点の厳密な再現ではない。
- 1回は`7000ms`。描画が遅い端末でもフレーム数に依存して長引かず、必要に応じて解像度と影を軽くする。
- 終了後は同じ電車の再生、別の電車、当該電車の図鑑を選べる。「おしまい」は再生中も押せる。名前を一度だけ読み上げ、控えめなモーター音と車輪の音を重ねる。
- 学習文字・名前の復習きっぷは表示しない。クイズの完成記録や図鑑への記録は既存の仕組みを使う。

## 実装

- `reward3d-catalog.js`：軽量の4車両メタデータ。
- `reward-cinema.js`：ダイアログ、読み込み、自動発車、音、操作、終了処理。
- `reward3d.js`：WebGL描画、7秒の時計、カメラ、車輪の回転、負荷調整。
- `reward3d-world.js`：高架橋、架線、街、川、木、空、反射環境。
- `reward3d-trains.js`：4形式の車体と車内・機器の造形。

Three.js 0.180.0を`vendor/three/`に同梱（MIT、LICENSE添付）。[公式ドキュメント](https://threejs.org/docs/)に基づくWebGLRenderer、InstancedMesh、PBR材質を使用する。通常のクイズ開始時は車両メタデータだけを読み、3D本体はごほうびを開く際に読み込む。アプリ動作中にCDNからライブラリやモデルを取得しない。

ウィンドウ・機器を共有ジオメトリとInstancedMeshで描き、検証画面の描画呼び出しは約170〜185回。WebGLを利用できない、またはコンテキストを失った場合は、図鑑の絵と「この端末ではイラストで表示しています」に切り替える。固定カメラを使う「動きを減らす」設定にも対応。

背景へ移動すると時計と音を止め、復帰後は残り時間から再開する。イラストへの代替表示も同じ。戻る・終了・別車両への変更では描画ループ、タイマー、音、ResizeObserver、GPU資源を破棄する。別車両へ切り替える際はcanvasも作り直し、失われたWebGLコンテキストを再利用しない。

## 検証

- `npm test`：全80件。4車両の形状・編成・車輪・寸法・資源解放、自動発車、7秒境界、読み込み中の終了、再生・別車両・図鑑、遅延ロード、背景中断と再開、代替表示を含む。
- `tests/reward-visual-browser.cjs`：実WebGLで4車両の各4時点を撮影。7秒の実時計、再生・別車両・図鑑の一致、390×844／320×667／667×375／320×375の操作領域と見切れ、動きを減らす設定、WebGLコンテキスト喪失を確認。
- `tests/android-browser.cjs`：PWA、オフライン、戻る・進む、ごほうび中の戻る、重複完走の防止を確認。
- `tests/word-browser.cjs`：音声3択・4択から5問完成して、新しいごほうびへ進む流れを320／390／1440pxで確認。
- 車両・画面のサブエージェントレビューを実施。従来標準5050にない窓上の赤線を削除し、長い路線名の改行と、カメラの先頭切れ・建物の遮蔽を修正した。

検証はWindowsのChromium系ブラウザとAndroid相当のエミュレーション。Android実機のGPU性能・音量は未確認。車両の外観を参考に作った軽量の3Dモデルで、実写映像やメーカーの精密CADではない。
