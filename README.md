# ひらがな でんしゃ

電車が好きな3歳のお子さん向けに、好きな電車の名前から文字の形と音に親しむ、小さな学習アプリです。

公開URL: https://tsubasa-narita.github.io/train-hiragana/

## あそびかた

- **なぞって はしろう**：清音46文字を指で書くモード。書き順・進む方向に沿って電車が走り、1文字完成すると対応する電車の絵が登場します。お手本、途中再開、行・文字の選択に対応。完成後は自分のペースで次へ進めます。[詳細・字形の出典・検証](docs/tracing.md)。

- **もじをみつけよう**：清音46文字すべてに対応。44文字は実在の列車・路線・鉄道会社の名前や愛称の先頭から出題。「を」「ん」のみ言葉や名前の途中を使います。「ぬ」は昔の沼尻軽便鉄道、「る」は昔の留萌本線です。[46文字の対応表](docs/kana-coverage.md)を参照してください。最初は見本ありの2択です。
- **行をえらぶ**：ホームで「あ・か・さ・た・な・は・ま・や・ら・わ」を複数選択できます。「あ→い→う→え→お」のように五十音順に出題します。1行だけなら毎回行の最初から。や行・わ行は3文字を順番に繰り返して5問です。複数行・「ぜんぶ」は5文字ずつ進み、完走した続きの位置をブラウザに保存します。図鑑から遊ぶと、その電車の行に切り替わって行の最初から始まります。
- **なまえをつなごう**：一文字ずつ選んで名前や言葉を連結します。選んでいない行の文字はあらかじめ入れ、選んだ行だけ練習できます。濁音・半濁音・小さい文字は元の行に含めます。ドラッグ操作は不要です。
- **でんしゃずかん**：61種類の電車・鉄道を最初から自由に閲覧。遊んだ電車にスタンプが付きます。犬の場面では、絵に登場する京急線のスタンプが付きます。名前の各文字も読み上げます。
- **あいうえお**：清音46文字、濁音、半濁音、小さい文字と長音符をタップして音を聞けます。
- **ごほうび電車**：5問すべて正解して旅を終えると、16種類からランダムな電車が走行音とともに画面を横切ります。虹の橋・駅でひとやすみ・星空急行の3種類の演出があります。電車と演出はそれぞれ直前と同じものを避け、「もういっかい はしる」で同じ電車を別の演出で何度でも再生できます。「つづける」で演出中にも先へ進めます。名前の連結では5つの名前・言葉を完成させたときだけ登場します。途中の正解はチャイムと文字表示で応援します。端末の「視差効果を減らす」設定では走行の代わりに静止表示します。

1回5駅。回答の制限時間、減点、連続日数の要求はありません。正解を約1秒見せて、自動で次の問題や文字へ進みます。5問目も約1秒後に完走画面とごほうびを表示します。待機中の連打は無視し、ホームへ戻った場合などは予約した遷移を取り消します。「いま すすむ」で待たずに進むこともできます。保護者向け設定から、文字見本を隠す3択にも変更できます（電車名は手がかりとして表示）。

## 開発

Node.js 20以上。外部npmパッケージは不要です。

```sh
npm run dev   # http://127.0.0.1:4173
npm test
npm run build # dist/ に静的ファイルを出力
```

ES Modulesを利用するため、index.htmlの直接ダブルクリックではなくHTTPサーバーで開いてください。

## GitHub Pages

ビルド不要のHTML/CSS/JavaScriptで、すべてのアセットは相対パスです。GitHubの Settings → Pages → Build and deployment で **Deploy from a branch / main / (root)** を指定すると公開できます。`.nojekyll` によりJekyll処理を無効にします。GitHub Actionsや秘密情報は不要です。

## 音声・保存・外部接続

- 案内は事前生成した日本語AI合成音声（Microsoft `ja-JP-NanamiNeural`、速度-8%、ピッチ+3Hz）609種類をMP3として同梱。端末によらず同じ声を再生します。「おうちのかたへ」で試聴できます。声は実在の特定人物を模倣したものではありません。
- 一文字の「は」は「ハ」として生成し、助詞の読みとの混同を避けています。小さい文字は「ちいさい、ツ」などと案内します。
- 音声ファイルが利用できない場合はWeb Speech APIに切り替えます。このときの声・発音は端末依存です。効果音はWeb Audio APIで合成します。
- 特にiOSではユーザー操作後に音声が利用可能になります。「もういちど きく」で再生できます。消音・画面移動で案内音声を停止します。
- 進捗・設定はlocalStorage（`train-hiragana-v1`）に保存。破損・使用不可の場合もプレイを継続できます。アカウント登録・広告・解析・アプリ側のデータ収集はありません。
- フォントはGoogle FontsのZen Maru Gothicを使用し、接続不可の場合はシステムの日本語フォントに切り替わります。OSの読み上げエンジンによってはネットワークを利用する場合があります。
- 初期の電車イラストは依頼者の既存プロジェクト `C:\develop\go-home-puzzle\public\images` から再利用。追加のクイズ用24枚・ごほうび用5枚は、既存の絵に合わせて組み込みImageGenで新規生成しました。[画像生成記録](docs/image-generation.md)に保存先とプロンプトをまとめています。ホームの電車は独自のSVGです。既存画像の一般向け再利用ライセンスは付与していません。

### 音声の再生成（開発時のみ）

生成には[edge-tts](https://github.com/rany2/edge-tts) 7.2.8を利用しています。[日本語音声の一覧](https://learn.microsoft.com/ja-jp/azure/ai-services/speech-service/language-support)も参照してください。通常のビルド・公開・プレイで音声生成サービスを呼び出すことはありません。

```sh
node scripts/voice-manifest.mjs
python -m pip install edge-tts==7.2.8
python scripts/generate-voice.py
```

生成時に送信するのは固定の学習用文言だけです。`assets/voice/lines.json` に画面で使う文言と読み方、音声の設定を記録しています。再生成スクリプトは生成済みファイルを再利用するため、声・読み方を変更した場合は対象MP3を取り除いてから実行してください。

## ファイル構成

- `src/app.js`：画面・読み上げ・ゲーム進行
- `src/data.js`：電車データ・問題生成・保存データ検証
- `src/reward.js`：ランダムなごほうび電車、走行演出、走行音、再生・終了管理
- `src/voice.js`：音声ファイル再生・停止・端末音声へのフォールバック
- `src/voice-lines.js`：問題やヒントの読み上げ文言
- `assets/voice/`：生成済み音声と生成用マニフェスト
- `src/style.css`：レスポンシブ表示・動きを減らす設定への対応
- `assets/trains/`：電車イラスト
- `tests/`：問題生成と保存の回帰テスト

電車を増やす場合は `assets/trains/` に画像を配置し、`src/data.js` の `TRAINS` に追加してください。

61種類の電車はそれぞれ専用画像を使用しています。「を」の場面と合わせてクイズ画像89枚（90候補）、ごほうび画像16枚です。清音46文字のすべてに2枚以上の候補があり、同じ文字で直前に見た画像を避けます。別の列車名と同じ列車の別景色を組み合わせています。実車デザインのレビュー・修正と生成プロンプトは [画像レビュー記録](docs/design-review.md) にまとめています。

## Androidへのインストール・戻る操作

AndroidのChromeで公開URLを開き、ブラウザメニューの「アプリをインストール」（または「ホーム画面に追加」→「インストール」）を選びます。インストール可能な場合は「おうちのかたへ」にもボタンを表示します。standalone表示のPWAとして、専用アイコンからブラウザのアドレスバーなしで起動します。インストールの表示文言や対応はブラウザにより異なります。

Androidの戻る操作・ブラウザの戻る/進むは、画面ごとの履歴に対応しています。電車の詳細→図鑑→ホーム、クイズ→ホーム、クイズから開いた設定→同じ問題、と戻れます。正解後のタイマーは移動時に停止し、同じ問題に戻ったときだけ再開します。問題ごとに履歴は増やさず、完走画面から戻っても正解数を二重に記録しません。ごほうび表示中の戻るは演出を閉じ、アプリのホームで戻ると通常どおりアプリ外へ戻ります。

`manifest.webmanifest` と192/512pxのPNG・maskableアイコンを同梱。`sw.js` はアプリ本体を保存し、閲覧した画像・音声は取得できたものだけ保存します。未閲覧の画像や音声まで完全オフラインで使えるわけではありません。オンラインでは新しいファイルを優先し、サービスワーカー更新で遊んでいる画面を強制再読み込みしません。キャッシュ名・対象パスをアプリ単位に分け、同じGitHub Pagesドメインの別アプリのキャッシュを削除しません。

実装参考：[MDN インストール可能なPWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)、[MDN History API](https://developer.mozilla.org/en-US/docs/Web/API/History_API/Working_with_the_History_API)。

今回の画像追加・検証結果は [バリエーション拡張記録](docs/expansion.md) を参照してください。
